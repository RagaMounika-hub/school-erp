# School ERP System

A full-stack School ERP Management System developed using the MERN Stack.

## Features

### Authentication
- JWT Authentication
- Role-Based Access
- Super Admin
- School Admin
- Teacher
- Student

### School Management
- Add Schools
- Update Schools
- Delete Schools

### Teacher Management
- Add Teachers
- Edit Teachers
- Delete Teachers

### Student Management
- Add Students
- Edit Students
- Delete Students

### Attendance Management
- Teacher Attendance
- Student Attendance
- Filter Attendance
- Export Attendance to Excel

### Leave Management
- Apply Leave
- Approve Leave
- Reject Leave

### Notice Board
- Add Notices
- View Notices
- School-wise Notices

### Dashboard
- Total Schools
- Total Teachers
- Total Students
- Attendance Charts

### Profile
- View Profile
- Update Profile

---

## Tech Stack

### Frontend
- React.js
- Vite
- Bootstrap
- Axios
- React Router
- Chart.js

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs

### Backend


### Frontend

```bash

npm install

```
